## Matt Pocock's skills

Copied unchanged from the release tag: the 27 skills listed in that release's `.claude-plugin/plugin.json`, moved from `skills/<area>/<name>/` to `<name>/` because Claude Code looks for project skills at `.claude/skills/<name>/SKILL.md`. The skills link to each other by `/name`, not by path, so the move breaks nothing.

Three names shadow Claude Code built-ins in this repository: `/code-review`, `/research` and `/prototype` run Matt's versions here. Matt does not rename skills for this; to get a built-in back, rename the folder and the `name:` field of the copy.

To update: check out a newer release tag of mattpocock/skills, copy the skills listed in its `plugin.json` the same way, and review the diff. Run `/setup-matt-pocock-skills` again only to change the issue tracker or label settings in `docs/agents/`.

## graphify

Generated by `graphify install --project` from graphify 0.9.88. The installer also wrote the `## graphify` section of `CLAUDE.md`, `.claude/CLAUDE.md` and the two `PreToolUse` hooks in `.claude/settings.json`.

The hooks were changed after install: each command first checks that `graphify` is on `PATH`, so sessions without graphify skip the hook instead of failing every tool call.

To update: change `GRAPHIFY_VERSION` in `.claude/hooks/session-start.sh` and `.github/workflows/graphify.yml` and `.github/workflows/claude.yml`, run `graphify install --project` with the new version, then restore the `PATH` check in `.claude/settings.json`. The installer rewrites those commands, and a second install run can replace them with an absolute path from your machine.
